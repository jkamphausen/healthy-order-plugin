# Healthy Order – Safari extension (research prototype)

Sorts the category bar on ubereats.com from healthy (first) to unhealthy (last)
and reduces the colour saturation of the icons the less healthy a category is.
All changes happen locally in the browser. No data is collected. Not affiliated with Uber.

Identical in behaviour to `chrome/` (`content.js` and `scores.js` are the same).

## Structure
- `extension/` – the actual web extension (Manifest V3, Safari 15.4+). **Develop only here.**
- `HealthyOrder/` – Xcode project (app wrapper for macOS and iOS), generated by the converter (see below).
  It points to `extension/`; the code is not duplicated.

## Generate the Xcode project (once, on a Mac)
Requirement: Xcode installed.
```
cd safari
xcrun safari-web-extension-converter extension \
  --project-location . \
  --app-name HealthyOrder \
  --bundle-identifier local.research.healthy-order \
  --macos-only --no-open --copy-resources
```
Without `--macos-only`, an iOS target is generated as well (Safari on iPhone).
Without `--copy-resources`, Xcode references the `extension/` folder directly, so changes there take effect immediately.

## Run (development)
1. Open `HealthyOrder/HealthyOrder.xcodeproj` in Xcode and run the macOS target (▶).
2. In Safari: **Settings → Extensions** → enable "Healthy Order".
   If the extension does not appear: **Safari → Settings → Advanced → "Show features for web developers"**,
   then **Develop → Allow Unsigned Extensions**.
3. Reload Uber Eats.

## Distribute (study)
To participants via **TestFlight** (Apple Developer account required, $99/year). For health research,
Apple requires consent and ethics approval (App Store Guideline 5.1.3).

## Customising
- Scores and saturation strength: `extension/scores.js`
- After changes, re-run the Xcode target and reload the page.
